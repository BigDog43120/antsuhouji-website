②四阶段流水线：从病种池到产品榜

Stage 1

病种池（只读）

做什么：加载已完成筛选的疾病候选池（分类、A/B/C 优先级标记），建立稳定 disease_id，校验输入完整性。
产出输入清单 + 校验记录 + 流程复现图
→
Stage 2+3

中国证据采集 + 双轨评价

做什么：按「官方数据 → 临床指南 → 学术研究 → 辅助价格」四层优先级，逐病种采集患病率、治疗现状、医保支付、饮食干预证据；每条证据定等级（L1–L4）；随后药物缺口、饮食机会两条轨独立评价，逐维写评分理由并引用证据。
产出证据库（jsonl，逐条带来源/日期/等级）+ 双轨逐维评价
→
Stage 4a

疾病定榜 Top10

做什么：用七维 A1_SCORE 公式加权计算全池总分，做敏感性分析（权重扰动、证据等级降级、区间端点），按规则打破同分，正式定榜前 10 病种。只有正式 Top10 进入产品筛选。
产出全池评分表（CSV）+ Top10 定榜（JSON）+ 定榜摘要（MD）
→
Stage 4b

日本产品筛选

做什么：为每个 Top10 病种建日本产品候选池 → 先过两项硬门槛（见③）→ 核验日本监管类别与证据 → 检索淘宝/京东同款 → 六维评分（见⑤）→ 按分取 10 款。
产出产品表（含逐款证据链）+ 渠道核验记录 + HTML 主报告
病种池 →（证据与双轨评价）→ 疾病榜 →（门槛与评分）→ 产品榜
为什么需要一套流程，而不是「直接问一次 AI」？

一次性生成的答案有三个致命弱点，而这套流程逐一设防：

一次性生成的弱点本流程的对策
编造——产品、链接、医保状态可能凭空生成每条记录强制绑定来源/日期/等级；关键字段未知必须标 pending，禁止填 0 冒充；「不得编造」写进每层规程
漂移——同一个问题两次答案不同，无法复现固定公式与权重、锚点定分、唯一 run_id、断点续跑；换口径（如 A/1b）必须显式立修正案
不可复核——说不出数字从哪来证据编号（如 E-K14-002）贯穿「证据→维度分→定榜→产品」全链，程序化验收 + 独立复核脚本全量复算

一句话：流程把「研究」从一次对话行为，变成可审计、可复现、可交接的工程产物。

③双硬门槛：产品先过准入，再谈评分

所有日本候选产品在打分之前，必须先过两道一票否决式门槛（veto gate）。顺序是强制的：先核验门槛，再评分——避免先看到高分再给门槛放水的倾向。

Gate 1 · 海南（乐城）已录入产品库核验

把候选产品与内部已录入产品库（海南乐城目录）逐一比对身份：

recorded → 一票否决not_recorded → 放行unknown → pending 暂缓

  • 身份匹配要求 JAN/GTIN + 制造商 + 品牌 + 品名 + 规格 五要素——仅名称近似不算同款。
  • 「无法访问」不等于「未录入」：库核验不可用时产品挂 pending，不得默认放行，也不得用公开互联网搜索替代内部库核验。

A/1 run 实测：海南目录实解析 626 条（器械 392 / 药品 211 / 食品 23）。

Gate 2 · 工业化成品核验

候选必须是可采购、可复购的工业化成品：

no（农作物/生鲜/原料）→ 一票否决yes → 放行unknown → pending 暂缓

  • 放行标准：明确制造商、稳定 SKU、商业化包装、可核实的成品身份。
  • 把普通农作物重新装袋，不自动视为工业化产品。

④疾病侧：双轨七维评分（A1_SCORE）

「哪些病种最值得研究」由七个维度决定，0–100 分，分属两条独立轨道：Track A 药物缺口（现在的药够不够好）与 Track B 饮食机会（积极「多吃什么」有没有证据）。

D 药物治疗难度 · TrackA
20
F 积极饮食干预证据 · TrackB
20
U 难根治/复发/进展 · TrackA
15
P 患者痛苦/QoL 损失 · TrackA
15
I 医保支付缺口 · TrackA
15
A 中国食品可获得性 · TrackB
8
E 日常摄入便利性 · TrackB

公式（双轨先各自归一，再加权合成）

DRUG_GAP_SCORE（药物缺口轨）= (20·D + 15·U + 15·P + 15·I) / 65 // 四维归一到 0–100
DIET_OPPORTUNITY_SCORE（饮食机会轨）= (20·F + 8·A + 7·E) / 35 // 三维归一到 0–100
A1_SCORE = 0.65 × DRUG_GAP + 0.35 × DIET_OPPORTUNITY // 药物缺口为主、饮食机会为辅

权威口径来自 data/disease_scores/a1_top10.json 的 formula 字段，与本页逐字一致。疾病负担、患者数量、不良反应等继续作为必采集信息进入报告与敏感性分析，但不占七维权重（避免体量大的病种自动得高分）。

各维锚点（0 / 50 / 100 分是什么状态）

维量的是什么0 分锚点50 分锚点100 分锚点

A 与 E 必须分开打分：「买得到食品」≠「吃得够有效剂量」。典型落差见 A/1 run：骨质疏松（D10）A=70 但 E=35——奶类供应充足，但实际钙摄入约 356mg 仅为推荐量一半。
Track A 与 Track B 各自具体关注什么？

Track A（药物缺口轨）关注：治疗是否困难；是否难以根治、易复发或持续进展；患者实际痛苦与生活质量损失；有效药物是否可获得、可负担，医保覆盖是否充分；不良反应与治疗依从性；留下的研发机会。

Track B（饮食机会轨）核心不是「少吃」，而是「多吃什么」：

  • 多吃什么食品、增加摄入什么营养元素，可能改善疾病相关临床结局？
  • 有没有临床证据？有效摄入量、持续时间、适用人群与终点是什么？
  • 中国消费者容易买到该食品吗？普通饮食能否达到研究中的摄入水平？
  • 是否需要工业化产品才能稳定获得有效剂量？
  • 过量摄入、药物相互作用、特殊人群风险是什么？

两轨独立保存、可单独审查——A/1 的 84 个双轨评价维（12 病种 × 7 维）就是这样逐维落盘的。

证据分级 L1–L4 与 tie-break 规则

每个维度的分数必须绑定证据，证据按可靠性分四级：

等级定义典型例子
L1官方目录/医保局/指南原文国家医保局目录、临床指南原文、药监局公告
L2权威机构转载/同行评审新华网转载官方表态、同行评议期刊
L3主流媒体/行业研究主流媒体报道、行业研究报告
L4商业榜单/电商页品牌榜单、电商商品页（无发布日期不采信）

注：A/1c run 在 L1–L4 之外增设 L5 最低档（全库仅 2 条记录），主力口径仍为 L1–L4 四档。

同分裁决（tie-break），权威口径逐字：证据质量（L1+L2 占比）＞ 患者痛苦 P ＞ 疾病负担（引用证据）；个别 run（如 A/1c）将第一判据细化为「组内最高证据等级」，判据次序一致，裁决依据必须写入定榜文件备查。

真实案例（A/1c run）：定榜第 10 名出现精确同分——K14（1型糖尿病）与 K16（苯丙酮尿症）A1_SCORE 均 64.35（非舍入伪同分，双方 DGS/DOS 均为有限小数）。该 run 定榜规则的第一判据（组内最高证据等级）双方同为 L1，落到第二判据 P 维 65 ＞ 55，K14 定第 10。裁决依据连同落榜原因一起写进定榜文件，可回查。
一条证据如何变成一个分数（真实例子：D06 的 I 维从区间收窄为定值 75）

以 A/1 run 的 D06（MASLD）医保缺口维为例：初始评分为区间 [70, 80] provisional——方向明确但证据强度不足。

补强证据（Phase R 修复阶段追加，全部带日期与编号）：

  • 国家医保局 2024-04-16 官方表态（新华网转载，L2 级）：司美格鲁肽注射液支付范围限定与成人 2 型糖尿病有关的两种情形，MASH/减重不在支付范围；
  • 2025 年版医保目录核验：唯一靶向药的 MASH 适应证不入保。

锚点对照定分：50 锚点＝存在支付限制/显著自付；100 锚点＝重要有效方案普遍难报销。两条证据显示「靶向药已获批但该适应证全自费、老药仅按糖尿病支付」——介于两锚之间偏高端，收窄为定值 75（firm）。

每个维度都这样定分：证据编号 → 来源与日期 → 等级 → 锚点对照 → 分数与状态（firm/provisional），修复记录另落盘 a1_dim_repairs.json，全程可回查。

缺失数据的铁律：unknown ≠ 0
  • 「无证据」「证据不足」「证据反对有效」是三种不同状态，必须分别记录，不得混写。
  • 任何维度缺失时，不得生成伪精确总分；只能给暂定区间并标注 provisional。
  • 正式 Top10 只从七个维度全部完成评价的病种中产生。
  • 每项分数绑定 evidence_id、评分理由、证据等级与评价日期；定榜前做权重扰动与证据等级敏感性分析（A/1 run 三情景：区间端点/权重 50-50 与 75-25/证据等级降级，Top10 成员仅在极端 50-50 等权情景出现一次边界轮动）。

⑤产品侧：六维评分与渠道核验

过了双硬门槛的产品才进入评分。六维各 0–100 分，权重合计 100%，公式逐字来自 data/product_scores/a1_top10x10.json：

PRODUCT_SCORE = 0.20×MATCH + 0.25×EVIDENCE + 0.20×CHANNEL + 0.15×COMPLIANCE + 0.10×DIFFERENTIATION + 0.10×SUPPLY

六维评分算例（真实数据：A/1 · D01 入选 #1「野菜一日これ一本トリプルケア」）
各维分数：MATCH=82 · EVIDENCE=75 · CHANNEL=100 · COMPLIANCE=78 · DIFFERENTIATION=78 · SUPPLY=85，代入公式：
PRODUCT_SCORE = 0.20×82 + 0.25×75 + 0.20×100 + 0.15×78 + 0.10×78 + 0.10×85 = 16.40 + 18.75 + 20.00 + 11.70 + 7.80 + 8.50 = 83.15
读法：EVIDENCE 与 CHANNEL 两个权重最高的维度合计贡献 38.75 分（占总分近半）——「证据硬」与「渠道空」是拉开总分的关键；而 SUPPLY 分再高（85）也只能贡献 8.5 分，因为权重只有 0.10。权重设计本身就是价值观：证据与机会优先，供应链只是及格线。

三条边界规则：① not_found_in_search 只表示本次检索未发现，不代表绝对不存在（每条记录都带检索日期与关键词）；② 已在中国平台销售不是一票否决，只影响 C 分——否决权在双硬门槛；③ 同款判定以 JAN/GTIN + 厂商 + 品牌 + 品名 + 规格为准，仅名称近似不算。任何平台无法核实时渠道分暂缺，不得臆测。
真实 C 分分布（A/1 · D01 高血压 10 款）：9 款 C=100（双平台当日均未发现同款），仅可果美无盐番茄汁因淘宝/京东均发现同款 C=0——总分 65.10 仍够入选第 10 位，但渠道先发优势归零；隔壁 D02 的 C 分则呈 100/50/0 三档分布（如 DHC 血糖值双重对策仅一平台发现同款，C=50）。C 分不决定「能不能入选」，只影响「排多前」——否决权始终在双硬门槛手里。
产品评分的其他纪律（防「高分低质」）
  • 日本的功能性表示（トクホ/FFC 届出）不等于中国允许同样宣称——COMPLIANCE 维按「转入中国」的可行性打分。
  • 必须检查配方、剂量、安全性、禁忌与药物相互作用；有严重安全/合规疑虑的标 needs_review，不得直接作为可销售推荐。
  • 关键字段未知一律 pending，不得填 0 冒充核验结果；缺少公开证据时如实标注，不得编造销量、供应商或监管批准。
  • 同一产品可服务多个病种，但必须分别证明适配性并披露重复；同一病种内不得用不同商家链接重复计算同一 SKU。
每病种 10 款的确定流程（9 步，不得为凑数降门槛）
  1. 建立日本产品候选池；
  2. 排除 Hainan 已录入产品（Gate 1）；
  3. 排除非工业化成品及农作物类（Gate 2）；
  4. 暂缓所有无法完成硬门槛核验的产品（pending 不入正式榜）；
  5. 核验日本类别、成分、剂量、证据与风险；
  6. 检索淘宝与京东同款情况；
  7. 计算六维产品分；
  8. 按分数降序选取 10 款合格产品；
  9. 保存未入选、否决与待核验记录及原因。

不足 10 款时如实输出「实际合格数 / 10 ＋ 缺口原因 ＋ 候选池规模 ＋ 否决数 ＋ 待核验数」——禁止编造产品、链接或核验结果凑数。

⑦可用场景：用真实世界数据寻找国外临床痛点产品——四连跑实录

⑧法规层面分析框架（结构化梳理 · 非法律意见）

⚠ 免责声明（先读）：本节为公开监管框架的结构化梳理，用于研究排序时的合规风险预判，不构成法律意见、注册建议或合规保证。法规与清单动态更新，一切以日本消费者厅/厚生劳动省及中国国家市场监督管理总局/NMPA 最新公告为准；周期与成本为公开信息量级估计，个案差异极大。任何产品进入中国市场前应取得专业法规顾问意见。

产品筛选里的 COMPLIANCE 维要回答的问题是：这款日本产品拿到中国来卖，监管上走哪条路？现有证据够不够？先看两侧的监管版图：

日本侧：健康相关产品的五类监管身份

特定保健用食品
（トクホ）消费者厅个别许可制：需医学·营养学证明（通常含人体临床试验），通过国家审查后许可标示特定保健用途。来源：消费者厅「特定保健用食品許可品目一覧」。
機能性表示食品
（FFC）2015 年创设的届出（备案）制：企业负责制，向消费者厅提交安全性+功能性科学依据的届出包，受理后即可销售，无需个案审查。来源：消费者厅「届出情報公表データベース」。
特別用途食品病者用（含病者用統合食）、孕产妇·乳儿用、高龄者用等特殊用途食品，个别许可（消费者厅/厚生劳动省体系），规格与审查最严。来源：消费者厅「特別用途食品許可・承認品目」。
栄養機能食品规格基准型：满足营养素含量规格（维生素/矿物质等 24 种目标成分）即可自行标示，无需个别审批或届出。来源：消费者厅「栄養表示基準」。
医薬品・医薬部外品药机法体系（厚生劳动省）：标榜疗效即落入医药品/医药品部外品（「薬用」等），需批准/认可，门槛最高，与食品体系并行。来源：医薬品医療機器等法。

日本四类食品制度速览（同场对比）

制度监管机制功能证据要求标示自由度查证入口
特定保健用食品（トクホ）消费者厅个别许可医学·营养学证明，通常含人体临床试验可标示特定保健用途（国审）消费者厅「許可品目一覧」
機能性表示食品（FFC）消费者厅届出制（企业责任）届出包：安全性＋功能性科学依据（可用研究综述路线）可标示机能性（企业担责）消费者厅「届出情報公表データベース」
特別用途食品个别许可（病者用/孕产妇·乳儿/高龄者）最严格：用途适配＋规格全项审查可标示特殊用途消费者厅「許可・承認品目」
栄養機能食品规格基准型（无需审批）无需功能研究，仅需符合营养素规格可标示营养素机能（限定文案）企业按「栄養表示基準」自证

对研究的含义：トクホ/特別用途食品的证据等级通常高于 FFC（国审 vs 企业届出），栄養機能食品的功能内涵最弱——EVIDENCE 维打分时按此分层。

中国侧：四条对应监管路径

保健食品
（注册/备案）「蓝帽子」：进口注册需生产国上市销售一年以上+功能学/毒理学等试验；维生素矿物质等符合原料目录的可走备案（较快）。来源：NMPA《保健食品注册与备案管理办法》（2016）。
特殊医学用途配方食品
（FSMP 注册）病者用营养配方：NMPA 注册制，非全营养/特定全营养分册，特定全营养需临床试验。来源：NMPA《特殊医学用途配方食品注册管理办法》（2016 施行，2024 修订）。
药品注册治疗性宣称的最严路径：NMPA《药品注册管理办法》，进口药注册，临床试验通常必需，周期与成本最高。
普通食品 + 跨境电商进口不做功能宣称的落地路径：按《跨境电子商务零售进口商品清单》（正面清单）网购保税/直购进口，无需国内注册，但不得宣称疾病预防治疗功能。来源：财政部等清单公告、商财发〔2018〕486 号。
这张表在流程里怎么用：Stage 4b 的 COMPLIANCE 维按「日本身份是否明确可核验」给基础分（能查到届出号/许可记录的身份，如トクホ、FFC，基础分高），再按「转入中国所选路径的证据缺口与周期成本」扣分。因此同款产品走跨境电商（不宣称）与走蓝帽子注册（要宣称）的合规评分含义完全不同——前者快而窄、后者慢而宽，COMPLIANCE 分数刻画的是「本次选定打法下的可行性与风险」。

跨境电商补充口径：个人年度交易限值 26,000 元、单次限值 5,000 元（超出部分按一般贸易监管），且商品须在正面清单内——来源：财关税〔2018〕49 号及历版清单公告。

中国四条路径横向对比（注册/备案的门槛差异）

路径触发条件核心证据门槛周期量级适合谁
保健食品注册（蓝帽子）要在标签/宣传中使用保健功能宣称进口产品需生产国上市销售一年以上＋功能学/毒理学/卫生学试验（指定检验机构出具）通常 2–3 年以上有长线品牌预算的厂商

A/1 实例映射（真实入选产品 × 上述框架）

例 1 · 可果美「野菜一日これ一本トリプルケア」（A/1 · D01 高血压入选 #1，83.15 分）
日本：機能性表示食品（FFC）→中国：跨境电商按普通食品进口（饮料类，正面清单内）
日本 FFC 届出（GABA 等机能成分）支撑其功能宣称，但转入中国走跨境电商即以普通食品身份销售、不得保留功能宣称——研究评分里的 EVIDENCE（75）证明成分有依据，COMPLIANCE（78）则确认这种「不宣称地卖」的路径可行。若未来要做功能宣称，则升格为蓝帽子注册路径，日本届出证据通常不够，需在中国重做功能学试验。
例 2 · 日本コカ・コーラ「からだすこやか茶W+」（A/1 · D02 糖尿病入选 #1，84.00 分）
日本：特定保健用食品（トクホ）→中国：跨境电商普通食品（首选）；或保健食品注册（若宣称功能）
トクホ是日本最严的食品功能许可（含人体试验），但中国不认可其许可互认：不宣称 → 跨境电商可行；宣称「抑制脂肪吸收/调节血糖」→ 进口保健食品注册，周期 2–3 年以上、成本数十万至百万级，日本试验数据仅供参考、需按中国体系重做。这正是 COMPLIANCE 维打 78 而非满分的逻辑：身份明确（日本许可可核验）但迁移宣称有成本。
例 3 · 大塚製薬「OS-1（オーエスワン）」（A/1c 儿童池全场最高 86.8 分）
日本：特別用途食品（病者用食品）→中国：FSMP 注册（对等路径）；或跨境电商普通食品（不按病者用宣称）
OS-1 在日本属「病者用食品」（脱水时水分·电解质补给，医疗机构常用），是五类中与病者需求绑得最紧的一类。对等的中国路径是 FSMP 注册——需 NMPA 注册资料、视类别可能需要临床试验，现有日本许可通常不够；而跨境电商路径可较快落地但不得使用「病者用」定位宣称。同一产品两条路的成本/周期差一个量级，是「先上量还是先做身份」的典型权衡样本。
